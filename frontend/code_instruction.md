# 前端编写规范文档

此文档用于描述和知道AI agent如何去为meetspace项目编写前端部分代码。

## 技术栈

| 名称     | 内容                                                         |
| -------- | ------------------------------------------------------------ |
| 前端框架 | Flutter 3.41.6-stable (Flutter SDK位于E:\env\flutter_windows_3.41.6-stable\flutter) |
| 网络请求 | dio/http                                                     |
| UI组件库 | Material 3，**在无样式说明的情况下使用默认样式**，同时有自定义的组件 |
| 字体样式 | 优先用GoogleFonts.inter()                                    |
| 国际化   | i18n，支持中文和英文                                         |

## 自定义组件 components

### 页面标题 page_title.dart

实现统一样式的页面标题，如：

![image-20260408191642061](C:\Users\Void\AppData\Roaming\Typora\typora-user-images\image-20260408191642061.png)

样式要求：字体样式设置为GoogleFonts.inter()，大小、尺寸和边距适宜。

应用场景：每个具有不同功能的页面，都必须用这个组件显示相应的信息。比如注册就显示"register"，主页就显示"home"等（遵循国际化）

### 活动卡片 activity_card.dart

实现一个带有活动信息的卡片组件

样式要求：圆角，可点击（显示活动详情页面），上方显示**活动图片**（没有就显示替代文本），在图片的上层右上角显示“已报名”（已报名则是绿色，未报名是灰色），下方显示**标题、简介、起止时间、人数范围**（字号、样式要能够区分这四个部分，人数范围可以只显示数字范围，配上人物标识）

（简介过长的情况下可以显示省略号），同样大小和边距自适应

边框颜色：READY - 绿色 CLOSED - 蓝色 OVER/DELETED - 灰色

### 统一样式按钮 custom_button.dart

对于用户注册、登录，活动的创建、修改、报名，使用相同样式的按钮

样式要求：Google风、简约美观即可（可自由发挥）

## 页面 pages

整体的页面颜色风格以浅色为主，**不要使用AI味十足的蓝紫渐变**，可以多使用白色、浅绿色、浅蓝色、浅黄色等看起来较为清新的配色

### 注册页面 register_page.dart

用于用户注册

样式要求：至简，左上方显示page_title组件，中部是输入框，用于输入所需字段，下部附上淡文字（MeetSpace v1.0 2026）

### 登录页面 login_page.dart

同上注册页面，不过用于登录

### 主页 home_page.dart

这里需要你进行卡片式的页面管理，即用一个BottomNavigationBar，添加三个按钮：发现、活动、我，分别切换至后续的活动发现页面、活动页面和个人资料页面。

样式要求：无特殊要求，作为一个页面容器就够了

---

### 发现页面 explore_page.dart

此页面用于展示推荐的活动（目前先展示数据库中含有的活动）和搜索框（用于搜索相关活动）

样式要求：使用Scaffold组织，顶部设置导航栏，包含返回上一级按钮；中部body区域：左上方显示page_title组件，其下方展示带有活动信息的活动卡片列表（可下滑）

### 活动页面 activity_page.dart

此页面用于展示和编辑用户相关活动的页面

样式要求：使用Scaffold组织，顶部设置导航栏，包含**返回上一级按钮、创建、参与、全部按钮**（分别显示用户创建的活动、参与的活动和全部活动，这里需要验证活动状态，为OVER和DELETED的活动卡片边框设置为灰且不可点击，READY边框为绿色，CLOSED边框为蓝色）；中部body区域：左上方显示page_title组件，其下方展示带有活动信息的活动卡片列表（可下滑）

### 个人资料页面 profile_page.dart

此页面用于展示和编辑用户个人资料、打开设置页面，请你自由发挥

### 设置页面 settings_page.dart

常用的设置配置，自由发挥

### 活动详情页面 activity_detail_page.dart（重要）

点击活动卡片即可跳转到对应的活动详情页面，用于显示活动详情、进行活动报名、修改、退出、删除等功能，需要你仔细思考**不同状态的活动应该支持哪些操作和不支持哪些操作**，并且实时更新

样式要求：使用Scaffold组织，顶部栏显示活动标题，body部分显示图片、描述、起止时间、报名ddl、详细地址、**高德地图导航**（导入高德api，用户点击时自动跳转高德地图导航至活动的经纬度信息处）
